# Benudhar Behera - Executive Portfolio & Resume Website

[![Live Website](https://img.shields.io/badge/Website-benudharind.github.io-06B6D4?style=for-the-badge&logo=github)](https://benudharind.github.io/)
[![LinkedIn](https://img.shields.io/badge/LinkedIn--0A66C2?style=for-the-badge&logo=linkedin)](https://linkedin.com/in/-benu/)

Executive portfolio & interactive resume website for **Benudhar Behera** (Senior Data & AI Engineering Leader | Multi-Cloud Architecture | Ex-Microsoft, Ex-Amazon), hosted directly on GitHub Pages.

---

## 🌟 Key Features

- **Executive Aesthetic & Design System**: Modern dark & light mode with persistent storage, glassmorphism cards, glowing ambient accents, and responsive layout.
- **Interactive Experience Timeline**: Detailed career progression across GlobalFoundries, Microsoft, Amazon, Altimetrik, PwC, and TCS with interactive category filters.
- **Technical Competency Matrix**: Categorized skill matrices (People Leadership, AWS Stack, Azure Stack, Data & Streaming, GenAI & Agentic Systems, AI Governance) with real-time keyword search.
- **Flagship Architecture Highlights**: Deep-dives into real-world Lakehouse, Agentic MCP workflows, and FinOps transformations.
- **Print & PDF-Ready Resume Export**: One-click print/PDF export formatted specifically with `@media print` CSS for recruiters and hiring managers.
- **Fast & Zero-Build**: Built with standard semantic HTML5, Vanilla CSS3, and modern JavaScript—lightning fast with 100/100 Lighthouse performance.

---

## 🛠️ Tech Stack

- **Markup & Semantics**: HTML5 with OpenGraph metadata and SEO optimization
- **Styling**: Vanilla CSS3 (Custom Variables, Flexbox/Grid, Glassmorphism, Responsive Media Queries)
- **Interactive Logic**: Vanilla ES6+ JavaScript
- **Icons & Typography**: Font Awesome 6.5, Google Fonts (*Outfit*, *Plus Jakarta Sans*, *JetBrains Mono*)
- **Hosting**: GitHub Pages (`benudharind.github.io`)

---

## 🚀 Local Development

To run or preview locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/benudharind/benudharind.github.io.git
   cd benudharind.github.io
   ```
2. Open `index.html` directly in any modern web browser, or run a local static server:
   ```bash
   python -m http.server 8000
   ```
3. Navigate to `http://localhost:8000`.
